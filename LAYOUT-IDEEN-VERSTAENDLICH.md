# Layout-Ideen: so verstehen Kunden es sofort (Stand 09.10.2026)

Grundregel aus unseren Zahlen (WAS-WIRKT.md): Frame 1 ist echt. Erklärung kommt danach, Stück für Stück.

| # | Format | Aufbau | Mair-Beispiel |
|---|---|---|---|
| E1 | Falsch → Richtig | 0–3 s typischer Fehler (echtes Bild), harter Schnitt auf den Beat, richtige Lösung. 8–12 s. | Heizkörper zugestellt → frei; Thermostat auf 5 → richtig eingestellt |
| E2 | Vorher/Nachher mit Einsatz | Start: hässliches Vorher + Frage ("Was würdest du hiermit machen?"), schneller Zeitraffer, lange auf dem Ergebnis bleiben | Altes Bad → neues Bad (eigener Fliesenleger); Ölkessel → Vitocal |
| E3 | Serie mit Nummer | Gleicher Aufbau, gleiche Einblendung "Teil 3", eine Sache ändert sich | Baustellen-Tagebuch Teil 1/2/3; "Rate das Baujahr #4" |
| E4 | App-Beweis | Echtes Gerät → echte App-Werte als große Karten → was heißt das für dich | E3/DC (L26), Viessmann ViCare-App |
| E5 | Eine Zahl, ein Bild | Echtes Foto + EINE große Zahl + ein Satz. Kein Rechenweg. | "3.600 € Öl im Jahr" auf echtem Öltank |
| E6 | Zeig-Finger-Erklärung | Patrick/Monteur zeigt mit der Hand auf Teile, je Teil ein Wort-Label | Wärmepumpe: Ventilator, Verdichter, Leitung |
| E7 | Pfeil-Fluss auf echtem Foto | Echtes Hausfoto, animierte Pfeile zeigen Energiefluss (Dach → Speicher → WP → Haus) | PV + Speicher + Wärmepumpe |
| E8 | POV kurz | "POV: Ölpreis steigt wieder" + Reaktion, nicht erklären | Ölkessel, Gasrechnung |

## Schnell-Check vor jedem Video
1. Frame 1 echt? 2. Hook in 5 Wörtern? 3. Max. eine Info pro Einblendung? 4. Unter 20 s? 5. Ergebnis lange genug zu sehen?
